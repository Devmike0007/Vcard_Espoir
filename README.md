# Espoir Compagnie — Carte de visite (vCard web)

Site statique (HTML/CSS/JS) prêt pour **GitHub Pages**.

## Déploiement sur GitHub Pages

1. Créez un dépôt GitHub (ex. `espoir-vcard`).
2. Copiez tout le contenu du dossier `vcard-web` à la **racine** du dépôt.
3. Sur GitHub : **Settings → Pages → Build and deployment → Source : Deploy from a branch**.
4. Choisissez la branche `main` et le dossier `/ (root)`.
5. Votre carte sera disponible à `https://<utilisateur>.github.io/<depot>/`.

## Structure

- `index.html` — page carte de visite
- `css/style.css` — styles
- `js/app.js` — partage / année
- `Espoir_Compagnie.vcf` — fichier contact téléchargeable

Aucun PHP ni build requis.

## Personnalisation

Modifiez les coordonnées dans `index.html` et `Espoir_Compagnie.vcf` en parallèle pour garder les infos alignées.
